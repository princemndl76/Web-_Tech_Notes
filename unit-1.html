Unit 1: Internet and web basics

History of the Internet

The Internet is a global network of networks that exchange data using the TCP/IP protocol suite.

  • 1969: ARPANET connects four US universities.
  • 1983: ARPANET switches to TCP/IP; this is treated as the birth of the Internet.
  • 1989-91: Tim Berners-Lee proposes the World Wide Web at CERN and builds the first browser and server.
  • 1993: Mosaic, the first widely used graphical browser, is released.
  • Later: commercial ISPs, broadband, mobile Internet and cloud services.

🎯 Exam Booster

Simple explanation: The Internet is a global system of interconnected computer networks that communicate using standard protocols, especially TCP/IP. Its development moved from research networks such as ARPANET to today’s commercial, mobile and cloud-based Internet.

Example: When you open a college notes website, your browser uses the Internet to communicate with a web server and receive HTML, CSS, images and other resources.

AdvantagesDisadvantages
  • Global communication and information sharing
  • Fast access to online services and resources
  • Supports education, business, banking and collaboration
  • Enables distributed applications and cloud services
  • Security and privacy risks
  • Dependence on network connectivity
  • Misinformation can spread quickly
  • Cyberattacks can affect users and organizations

World Wide Web and HTML

The Web is a service that runs on the Internet. It links documents (web pages) through hyperlinks and identifies them with URLs.

HTML (HyperText Markup Language) describes the structure of a page using tags.

<!DOCTYPE html>
<html>
  <head><title>My page</title></head>
  <body>
    <h1>Hello</h1>
    <p>This is a paragraph.</p>
    <a href="https://example.com">A link</a>
  </body>
</html>

A URL has the form scheme://host:port/path?query#fragment.

🎯 Exam Booster

Simple explanation: The World Wide Web is a service running on the Internet that provides interlinked resources through URLs and web protocols. HTML (HyperText Markup Language) defines the structure and meaning of web documents using elements and attributes.

Example: An HTML page can contain a heading, paragraph, image, hyperlink, table and form.

AdvantagesDisadvantages
  • Simple and widely supported
  • Works across operating systems and browsers
  • Supports hyperlinks and multimedia
  • Provides semantic structure for web pages
  • HTML alone does not provide advanced styling
  • HTML is client-side markup, not a programming language
  • Incorrect markup can reduce accessibility and maintainability

Protocols: HTTP and SMTP

HTTP (HyperText Transfer Protocol) is a stateless request-response protocol between a client (browser) and a server. Default port: 80 (HTTPS: 443).

  • Methods: GET (read), POST (send data), PUT (replace), DELETE (remove), HEAD.
  • Status codes: 200 OK, 301 Moved, 404 Not Found, 500 Server Error.
  • Stateless: the server keeps no memory of earlier requests; cookies and sessions add state.

SMTP (Simple Mail Transfer Protocol) sends email from a client to a server and between servers. Default port: 25 (587 for submission).

🎯 Exam Booster

Simple explanation: HTTP is used for transferring web resources between clients and servers. SMTP is an email transport protocol used to submit and relay outgoing email.

Example: A browser sends an HTTP GET request for /index.html. An email client may submit an outgoing message through SMTP.

AdvantagesDisadvantages
  • Standardized communication
  • Interoperability between different systems
  • HTTP supports many request methods and media types
  • SMTP supports reliable mail transfer between servers
  • HTTP without TLS does not protect confidentiality
  • HTTP is stateless and needs cookies/sessions for application state
  • SMTP itself is not the protocol used to read received mail

Protocols: POP3, MIME and IMAP

POP3 (Post Office Protocol) downloads mail from the server to one device, usually deleting it from the server. Port 110.

IMAP (Internet Message Access Protocol) keeps mail on the server and syncs folders across devices. Port 143.

MIME (Multipurpose Internet Mail Extensions) lets email carry non-text content such as images, audio and attachments by labelling each part with a content type, for example image/png.

ProtocolJobPort
SMTPSend mail25 / 587
POP3Download mail110
IMAPRead mail on server143

🎯 Exam Booster

Simple explanation: POP3 retrieves email, IMAP manages and synchronizes mail stored on a server, and MIME extends email formats so messages can carry attachments and different media types.

Example: With IMAP, the same inbox can stay synchronized on a laptop and phone. MIME can label an attachment as image/png.

AdvantagesDisadvantages
  • IMAP supports multi-device synchronization
  • POP3 can be simple for local downloading
  • MIME supports attachments and rich message content
  • POP3 can be inconvenient for multiple devices
  • IMAP depends more on server storage and connectivity
  • Email security still requires TLS/authentication mechanisms

Domain Name Server (DNS)

DNS translates human-readable domain names (example.com) into IP addresses.

Lookup steps:

  1. Browser checks its cache, then the OS cache.
  2. Request goes to the recursive resolver (usually the ISP's).
  3. Resolver asks a root server, then the TLD server (.com), then the authoritative server for the domain.
  4. The IP address is returned and cached.

Common records: A (IPv4), AAAA (IPv6), CNAME (alias), MX (mail server), NS (name server).

🎯 Exam Booster

Simple explanation: DNS is a distributed naming system that maps human-readable domain names to IP addresses and provides other records such as MX and CNAME.

Example: Typing example.com causes a resolver to obtain the IP address needed to connect to the site.

AdvantagesDisadvantages
  • Human-friendly names
  • Distributed and scalable architecture
  • Caching reduces lookup time and traffic
  • Supports different record types
  • DNS spoofing/cache poisoning can be security risks
  • Incorrect DNS configuration can make services unreachable
  • Propagation/caching can delay changes

Web browsers

A web browser requests, receives and renders web content.

  • Main parts: user interface, browser engine, rendering engine, networking, JavaScript interpreter, data storage.
  • Rendering engines: Blink (Chrome, Edge), Gecko (Firefox), WebKit (Safari).
  • Process: fetch HTML, build the DOM, apply CSS, run JavaScript, paint the page.

🎯 Exam Booster

Simple explanation: A web browser is client software that retrieves web resources, builds a document model, applies CSS, executes JavaScript and renders the final page for the user.

Example: Chrome, Firefox and Safari request an HTML page, download its CSS/JS and render the interface.

AdvantagesDisadvantages
  • User-friendly interface
  • Supports HTML, CSS and JavaScript
  • Provides developer tools and security features
  • Works with many web services
  • Consumes memory and CPU
  • Browser differences can affect rendering
  • Extensions/scripts can create privacy or security risks

Web servers

A web server stores web content and answers HTTP requests.

  • Static content: files sent as they are (HTML, CSS, images).
  • Dynamic content: pages generated by server-side programs (PHP, Node.js, Java servlets).
  • Examples: Apache HTTP Server, Nginx, Microsoft IIS, Apache Tomcat.

🎯 Exam Booster

Simple explanation: A web server is software and the underlying host environment that accepts HTTP requests and returns resources or generated responses.

Example: Nginx may serve HTML/CSS files directly, while an application server can generate dynamic data before returning an HTTP response.

AdvantagesDisadvantages
  • Centralized delivery of web resources
  • Can handle many concurrent clients
  • Supports security, logging, caching and compression
  • Can serve both static and dynamic applications
  • Requires configuration and maintenance
  • Poorly configured servers can expose security vulnerabilities
  • High traffic may require scaling and load balancing

Client-server model and IP addressing

In the client-server model a client (browser) sends a request and a server sends back a response. One server can serve many clients.

  • IP address: unique numeric address of a device. IPv4 is 32-bit (192.168.1.1); IPv6 is 128-bit.
  • Port: identifies the application on a host (HTTP 80, HTTPS 443, SMTP 25, DNS 53).
  • Socket: IP address + port.

🎯 Exam Booster

Simple explanation: In the client-server model, clients request services and servers provide them. IP addresses identify hosts/interfaces at the network layer, while ports identify application endpoints.

Example: A browser at a client device connects to a server IP on TCP port 443 for HTTPS.

AdvantagesDisadvantages
  • Centralized resource management
  • Easy service sharing
  • Servers can enforce common policies
  • Supports many clients
  • Server failure can affect many clients
  • Server infrastructure can become a bottleneck
  • Network latency affects user experience

🎯 Exam Booster

Simple explanation: An HTTP exchange consists of a client request and a server response. Requests contain a method, target and headers; responses contain a status code, headers and optionally a body.

Example: GET /notes.html followed by HTTP/1.1 200 OK and an HTML response body.

AdvantagesDisadvantages

  • Extensible headers and media types
  • Stateless design scales well for many applications
  • Repeated requests can add overhead

  • HTTP without TLS exposes traffic to interception

HTTPS gives confidentiality (encryption), integrity (data is not altered) and authentication (the server is who it claims to be).

🎯 Exam Booster

Simple explanation: HTTPS is HTTP protected by TLS. It provides encryption, integrity and server authentication, while ordinary HTTP sends application data without TLS protection.

Example: A login form should normally be submitted over HTTPS so credentials are encrypted in transit.

AdvantagesDisadvantages
  • HTTPS protects confidentiality
  • Detects tampering through integrity protection
  • Certificates help authenticate servers
  • TLS adds processing and certificate-management requirements
  • Configuration mistakes can weaken security
  • HTTPS does not make an insecure application automatically safe

Quick revision

  • Internet = network of networks using TCP/IP; the Web is a service on top of it.
  • HTTP is stateless; cookies and sessions add state. HTTPS = HTTP + TLS.
  • SMTP sends mail; POP3 downloads; IMAP syncs on server; MIME adds attachments.
  • DNS maps domain names to IP addresses (A, AAAA, CNAME, MX, NS records).
  • Ports: HTTP 80, HTTPS 443, SMTP 25, POP3 110, IMAP 143, DNS 53.
  • Browser = client that renders content; web server = software that answers HTTP requests.

Important questions by Bloom level

Course outcome: CO1. Start with Remember and Understand for short answers, and practise Apply, Analyze, Evaluate and Create for long answers.

L1 Remember

  1. Define the Internet and the World Wide Web.
  2. List the full forms of HTTP, SMTP, POP3, IMAP, MIME and DNS.
  3. Name any four HTTP methods and four status codes.
  4. State the default port numbers of HTTP, HTTPS, SMTP and POP3.

L2 Understand

  1. Explain the working of HTTP with a request and response example.
  2. Differentiate POP3 and IMAP.
  3. Explain the role of MIME in email.
  4. Describe how DNS resolves a domain name step by step.
  5. Explain why HTTP is called a stateless protocol.

L3 Apply

  1. Write the HTTP request your browser sends to fetch /notes.html from www.example.com.
  2. Show how a DNS lookup of www.quantumeducation.com flows through root, TLD and authoritative servers.
  3. Choose the protocol (SMTP, POP3 or IMAP) for: sending mail, reading mail on phone and laptop, and downloading mail for offline use.

L4 Analyze

  1. Compare HTTP and HTTPS in terms of security, port and certificates.
  2. Analyze what happens from typing a URL to seeing the page rendered.

L5 Evaluate

  1. Justify why IMAP is preferred over POP3 for users with several devices.
  2. Judge the importance of DNS caching for web performance.

L6 Create

  1. Design a simple client-server setup for a college notes website and name the protocols involved.
